# Student Result Management System

A simple SQL/DBMS project for managing students, subjects, and marks.

## Files

1. `01_tables.sql` - Creates the database and tables.
2. `02_insertion.sql` - Inserts sample students, subjects, and marks.
3. `03_queries.sql` - Contains the required SQL queries and extra practice queries.

## Database Schema

### Students
- StudentID
- Name
- Branch
- Year

### Subjects
- SubjectID
- SubjectName
- Credits

### Marks
- StudentID
- SubjectID
- Marks

## Required Tasks

- Find the topper in DBMS.
- Find students scoring above 80 in all subjects.
- Calculate average marks of each subject.
- Find students who failed.
- Display CGPA.

## How to Run

Run the files in this order:

```text
01_tables.sql
02_insertion.sql
03_queries.sql
```

The SQL is written for MySQL.
